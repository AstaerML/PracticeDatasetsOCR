# PracticeDatasetsOCR
Папка "Practice_Tests" содержит в себе 2 набора данных с соответствующими эталонными текстами для проверки OCR алгоритмов.
- Набор данных "Photo_Book_Test" содержит в себе 5 изображений, которые представляют собой первые 5 страниц из рассказа "Дагон" Говарда Филлипса Лавкрафта, эталонный текст для изображений содержится в файле "Photo_Book_Test_Reference.json".
- Набор данных "Photo_Images_Test содержит в себе 5 изображений, которые представляют собой случайные фото вывесок/плакатов сделанных на улице. Эталонный текст для изображений из данного набора содержится в файле "Photo_Images_Test_Reference.json".
